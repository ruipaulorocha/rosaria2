# rosaria2
ROS2 version of the legacy rosaria (https://github.com/amor-ros-pkg/rosaria) package

This driver supports several well-known mobile robot platforms from Adept Robotics, including the Pioneer P3-DX2.

The driver was ported to ROS Jazzy (a ROS 2 distribution) and tested successfully in this ROS distro by Rui P. Rocha (ISR - University of Coimbra, [rprocha@isr.uc.pt](mailto:rprocha@isr.uc.pt)) on Sep. 2024.

On May 2025, this branch of the repository was created to make the driver also available in ROS Foxy (thus an Ubuntu 20 friendly version).

For information on how to use RosAria, see http://wiki.ros.org/ROSARIA, especially <http://wiki.ros.org/ROSARIA/Tutorials/How to use ROSARIA>.
